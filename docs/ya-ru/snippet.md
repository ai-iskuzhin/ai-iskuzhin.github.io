# Сниппет

Конспект правил Яндекса. Первоисточник: Яндекс Вебмастер → Справка → «Сниппет».

Сниппет — блок информации о странице сайта, который отображается в результатах
поиска. Состоит из заголовка и описания страницы и может содержать
дополнительную информацию о сайте.

Благодаря сниппету пользователь получает представление о странице или нужную
информацию, не заходя на сайт. Качество сниппета влияет на CTR: если сниппет
составлен грамотно, пользователи чаще переходят на сайт.

## Что может отображаться в сниппете

- Заголовок и описание.
- Фавиконка.
- Адрес сайта. На внутренних страницах он может отображаться в виде
  навигационной цепочки (хлебных крошек).
- Дата публикации.
- Метки, если у сайта есть знаки.

Дополнительно сниппет может содержать быстрые ссылки, адрес организации,
изображения и другие данные.

Посмотреть текущее отображение сайта в поиске можно в Вебмастере на странице
**Представление в поиске**.

## Как это закрыто на нашем сайте

| Элемент сниппета | Статус | Источник |
| --- | --- | --- |
| Заголовок | есть, свой на каждый маршрут | [src/seo.ts:52](../../src/seo.ts#L52) — `metaFor()` |
| Описание | есть, обрезано до 160 символов | [src/seo.ts:37](../../src/seo.ts#L37) — `clamp()` |
| Фавиконка | есть (`.ico` + PNG 96×96) | [index.html:11-12](../../index.html#L11-L12) |
| Навигационная цепочка | JSON-LD `BreadcrumbList` | [src/seo.ts:160](../../src/seo.ts#L160) — `crumbs()` |
| Дата публикации | `datePublished` у постов блога | [src/seo.ts:261](../../src/seo.ts#L261) |

## Про хлебные крошки и JSON-LD

Разметка `BreadcrumbList` на сайте отдаётся только в формате JSON-LD. Яндекс
исторически документирует поддержку Schema.org через **микроразметку
(microdata) и RDFa**, и поддержка JSON-LD у него уже, чем у Google. Это стоит
проверить в [валидаторе микроразметки](https://webmaster.yandex.ru/tools/microtest/),
прежде чем считать навигационную цепочку закрытой задачей: возможно, для Яндекса
крошки придётся продублировать в microdata прямо в вёрстке.

Задача заведена в [plan-deystviy.md](plan-deystviy.md).
