# Быстрые ссылки

Конспект правил Яндекса. Первоисточник: Яндекс Вебмастер → Справка →
«Формирование быстрых ссылок».

Быстрые ссылки делают сниппет сайта информативнее: пользователь видит важные
разделы прямо в выдаче и попадает в них за один клик.

## Условия создания

Быстрые ссылки формируются **автоматически роботом Яндекса**. Заявки на создание
не существует — можно только привести сайт в состояние, при котором робот их
построит. Робот определяет наиболее посещаемые разделы сайта и создаёт быстрые
ссылки при следующих условиях:

1. **Короткие и понятные названия страниц** точно отражают их содержание.
2. Ссылка создаётся **только на основе внутренних ссылок сайта**. Текст ссылки
   при этом может состоять из названий как внутренних, так и внешних страниц.
3. **Разделы и подразделы выделены в меню** — либо являются самыми популярными
   переходами со страницы, для которой формируются быстрые ссылки.

Из третьего пункта следует главное практическое ограничение: быстрая ссылка —
это ссылка на **другой URL**. Якорь вида `/#contact` ведёт на тот же URL, что и
`/`, поэтому кандидатом быть не может.

## Формы отображения

Быстрые ссылки показываются и для главной, и для внутренних страниц. Есть два
вида:

- **Ссылки** — строка/сетка ссылок под сниппетом.
- **Навигационный ответ** — крупный блок, обычно по брендовому запросу.

Условия для каждого вида:

| Условие | Ссылки | Навигационный ответ |
| --- | :---: | :---: |
| Быстрые ссылки сформированы | ✅ | ✅ |
| Страница входит в ТОП-5 результатов поиска | — | ✅ |
| На выдаче нет навигационного ответа у страницы выше по позициям | — | ✅ |
| Алгоритмы считают страницу и её быстрые ссылки релевантным ответом на запрос | — | ✅ |

Наличие сформированных быстрых ссылок проверяется в Вебмастере на странице
**Представление в поиске → Быстрые ссылки**.

## Почему быстрые ссылки пропадают

При очередном обходе сайта робот может удалить быструю ссылку, если:

- робот нашёл более подходящую страницу для быстрой ссылки;
- структура сайта изменилась;
- сайт перестал соответствовать условиям формирования.

Отсюда вывод для разработки: **менять URL разделов и тексты пунктов меню — это
операция с ценой**. Каждое переименование обнуляет накопленный сигнал и
запускает переформирование с нуля.

## Что из этого управляемо

| Фактор | Управляем из кода | Комментарий |
| --- | --- | --- |
| Разделы выделены в меню | да | состав и порядок пунктов навигации |
| Внутренние ссылки на разделы | да | ссылки должны быть в HTML, а не только в JS |
| Короткие названия страниц | да | `<title>` и текст ссылки |
| Посещаемость разделов | нет | зависит от трафика и поведения пользователей |
| Попадание в ТОП-5 | нет | зависит от ранжирования |
